手把手教你 0 元建立 Shopify 測試商店，從註冊到建站完整流程大公開！

發表於2025-06-06|更新於2025-06-07|工具教學Shopify
|閱讀量:

你是不是也曾經對 Shopify 很好奇，但一看到只有幾天試用期就默默關掉網頁？
這篇文章想分享超實用卻很少人知道的小撇步！怎麼用 0 元建立 Shopify 試用商店，讓你可以慢慢摸索、練習、甚至架出完整網站，等你真的準備好了再付錢也不遲！

不需要綁信用卡、不需要先付費，也不用怕試用期到就白忙一場。
只要照著這篇教學一步步操作，你也可以馬上擁有一個可以長期使用的 Shopify 免費商店 ✨

為什麼要建立 Shopify 免費商店？

如果你去 Shopify 官網註冊帳號，會發現試用期超級短 —— 只有 3 天，之後的話則是可以以 $1 美金訂閱 3 個月，如果還想要繼續使用就必須依據所選擇的方案付錢了。

但你知道嗎？只要申請一個「Shopify Partner 帳號」，你就可以建立一個：

✅ 免費、無限期使用的開發商店
✅ 功能跟正式商店一模一樣(只是不能正式上線賣產品)
✅ 可以自己練習、開發、測試，也可以用來給客戶 demo

而且不用綁信用卡、不用花一毛錢，就可以一路玩到爽 😎
根本是 Shopify 給開發者和創作者最大的福利之一啊！！！！！

什麼是 Shopify Partner？適合誰申請？

Shopify Partner 是 Shopify 為設計師、開發者、顧問、行銷人員提供的官方平台，可以協助客戶建站、開發 App、主題等，也能自己學習練習，只要有電商興趣的人都能免費申請，沒有門檻！

也就是說！！！！！任何人都可以建立自己的測試商店！！

如果你對於 Shopify 還不是很了解，但是有興趣，想知道商店到底怎麼運作、有哪些功能、是否有達到你的期待，你就很適合申請 Shopify Partner！　

馬上跟著我開始吧！

0 元建立試用商店的流程

第一步：註冊帳號

前往 Shopify Partner 頁面，點選右上角註冊。

使用平台帳號註冊

在這邊選擇想要使用的平台帳號註冊就可以了，非常方便。

基本資料填寫

這邊可以直接選「建立及設定新合作夥伴組織」就可以了，如果你屬於某一個團隊，而那個團隊已經有建立了組織，你也可以選擇「加入現有的合作夥伴組織」就能夠跟大家一起開發 Shopify。

國家的部分會影響到 Shopify 可以提供的服務，有部分服務在台灣是尚未開放的，但我們只是測試的話，還是先選擇台灣，之後再慢慢了解有哪些差異。


這邊如果你是公司、自己有經營事業，就可以填入公司的正式資料。
但如果你像我一樣只是自己玩玩看的話，可以填入個人的地址、郵件和電話就好囉。

第二步：建立商店

如果你進入到像這樣的頁面，就表示註冊成功囉！
接下來就可以開始建立 Shopify 商店了！

你可以直接在商店這一個區塊選擇新增商店，並選擇建立開發商店。

或是從側邊的商店進來後再點選新增商店。

接下來 Shopify 提供兩種類型的測試商店，第一種是為客戶建立商店這個商店未來可以轉移給客戶，甚至如果客戶開始訂閱 Shopify 之後還能夠從中抽成，但是如果是這種商店，為了保護客戶的權益，是沒辦法使用 API 的，詳細的資訊可以參考Shopify 的合作夥伴收益一文。

我接下來還會跟大家分享要如何利用 Shopify GraphGL API 來批量管理商店、客製化自己的管理需求等等，因此我們在這邊選擇建立商店以執行測試和組件作業的選項，在功能上就比較不會受限，但是未來就不能夠轉移給客戶唷！

選擇完成後，填寫商店名稱，這是會與網址連動的，所以請注意這邊請以小寫並且可以使用「-」符號來連接，比如：

shao-example

組件版本建議選擇目前版本，會比較穩定，開發人員預覽則是可以提前體驗尚未穩定的新功能。

資料和設定可以依個人需求選擇，這邊一樣建議以空白商店開始，選擇以測試資料開始的話就會自動幫你帶入測試的產品資訊、訂單等等，但是會比較亂，如果想體驗從頭架設一個 Shopify 網站，還是從空白開始吧！

最後點選建立開發商店就可以囉

第三步：進入開發商店

當你看到這個後台畫面，就表示你的商店建立成功囉！點選左側選單中網路商店的眼睛，就可以查看你的線上商店囉！

這個時候我們可以來檢查一下商店的網址，你有發現跟剛剛我們設定的商店名稱相同嗎？這就是你商店的預設網址！未來也可以自行購買網域來取代掉這個網址。

不過要注意的一點是，如果不是經由網站後台進入你的商店前台的話，直接輸入網址想要進入前台，可能會被要求提供密碼，因為目前我們的網站尚在測試階段。

那麼要如何查看你的密碼呢？

你可以在偏好設定中重新設定你的密碼，以後就可以利用這個密碼直接進入前台查看內容囉！！
當然也可以把這個網址和密碼提供給其他人，這樣你的夥伴或是客戶也能看到網站的內容！

免費商店能做什麼？不能做什麼？

最後來一點小提醒，你可以在這個免費商店做到：

✅ 自訂前台主題、後台功能
✅ 安裝 App、設計流程、串接 API
✅ 客製開發、測試付款流程

但是也有以下限制：
❌ 不能用來正式收款賣商品

也就是說這是個僅供展示、練習、客戶審核用的商店。
